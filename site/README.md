# ICAIO draft site (review only)

Static HTML draft for visual reference and evidence of progress. Not the production build
(production basis remains Astro + TypeScript + Tailwind, per docs/04-approved-decisions.md).

## View it locally
- Double-click `serve.command` (macOS), then open http://localhost:8080
- Or: `cd site && python3 -m http.server 8080`
- Or simply open `index.html` in a browser.

## Hero images
Six AI-generated, illustrative boardroom scenes (Sydney, Melbourne, Brisbane, Canberra, Perth, Adelaide),
captioned "Illustrative image. Not ACAIO members." Expected at `assets/img/hero-<city>.jpg`.
If a local file is missing, the page falls back to the Figma-hosted original (links expire about 19 Oct 2026).
Replace with commissioned or licensed photography before any public release.

## Editing
Pages are generated by `../build.py` (shared header/footer). Edit it, then run `python3 build.py` from the project root.
Yellow [bracketed] text marks placeholders that need Nick's input.

## Safeguards
- `noindex, nofollow` on every page; draft banner on every page.
- Forms validate but never send data.
