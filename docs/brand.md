# ICAIO visual direction

Contemporary professional institution. Editorial typography, warm light reading surfaces, deep ink, restrained teal, generous space and clear rules. Typography and the eight-domain model provide identity without AI stock imagery.

Prototype tokens:

| Role | Proposed value |
|---|---|
| Paper | #F5F3EC |
| Surface | #FFFFFF |
| Ink | #172D36 |
| Secondary text | #4B6066 |
| Teal | #285F5A |
| Dark surface text | #F5F3EC |
| Dividers | #C8D0CA |
| Display | Georgia, serif, as a locally available wireframe stand-in |
| Body | Arial, sans-serif, as a locally available wireframe stand-in |

Font selection and licensing are pending the design reference stage. The ICAIO text mark in the preview is a layout placeholder, not a commissioned or approved logo.

No seals, badges, partner logos or decorative AI graphics. Photography exception (12 October 2026): the homepage hero uses rotating boardroom images with Australian capital-city views, captioned as illustrative. These are AI-generated drafts, to be replaced with commissioned or licensed photography before launch. All eight domains receive equal visual weight. Preview contains no animation.
