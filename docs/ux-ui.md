# Homepage reference

## Purpose

Make the case for a professional discipline and invite founding participation. This stage resolves copy, order and reading hierarchy before production design.

## Composition

1. Compact header with ICAIO text mark, section navigation and persistent EOI action.
2. Editorial hero: full institution name, approved two-part proposition, formation statement, primary action and quiet discipline link.
3. Why now: short argument in an asymmetric two-column layout.
4. Discipline and eight domains: integration statement as a band across the top, then a 4 by 2 model on desktop, single reading sequence on mobile. No interactivity is required to access definitions.
5. Why ICAIO: four mandates as ruled rows, not another card grid.
6. Founding Council: dark section with proposed contribution and explicit Board distinction.
7. Initial agenda: five proposed outputs as a clear list. No status badges implying completed work.
8. Independence: six principles in two columns, then one column on mobile.
9. Closing invitation: primary EOI and quieter general interest action.

## Wireframe behaviour

Header links navigate to homepage sections for review. They are not the eventual cross-page routing. CTA opens an inline prototype destination explaining the planned handoff. No personal data is collected and no false submission success is shown. A dismissible review note identifies draft status.

Mobile header keeps the compact EOI action visible and uses a native disclosure menu. Main text stacks, CTA labels wrap, all domain descriptions remain visible.

## Reusable components

BaseLayout, SiteHeader, MobileNavigation, SiteFooter, Container, Section, Button, TextLink, InstitutionalHero, EnterpriseLeadershipModel, MandateList, FoundingInvitation, ProposedAgendaList, PrinciplesList, ClosingInvitation. Form components belong to the later functional implementation.
